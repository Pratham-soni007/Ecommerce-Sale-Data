# E-Commerce Sales & Customer Analytics

## Project Overview

This project analyzes e-commerce sales and customer transaction data to identify
sales trends, customer behavior, product performance, profitability, and return patterns.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Key Analysis

- Sales and revenue analysis
- Yearly and monthly sales trends
- Product category performance
- Product-level profitability
- Loss-making product identification
- Customer segmentation
- Customer revenue analysis
- Geographic sales analysis
- Return-rate analysis
- Order-status analysis

##  Key Findings

- Total Revenue: ₹244.99M
- Total Orders: 100,000
- Unique Customers: 22,820
- Items Sold: 585,640
- Average Order Value: ₹24,498.99
- Electronics generated the highest revenue.
- Electronics had a relatively low profit margin compared with several other categories.
- 33 products were identified as loss-making.
- Loss-making products generated a combined loss of approximately ₹13.58M.
- VIP customers contributed approximately 67% of total revenue.
- Maharashtra was the highest-revenue state.
- Overall return rate was approximately 9.51%.
